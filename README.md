# Bike-Purchased
This project analyzes customer data to predict whether a customer is likely to purchase a bike using Logistic Regression. It involves data preprocessing, visualization, model building, and evaluation — all done in Python using a Jupyter Notebook.

⸻

📁 Files Included
	•	bike_prediction.ipynb: Main Jupyter Notebook with code and analysis.
	•	bike_data.csv: Dataset used for training and testing.
	•	README.md: Project overview and instructions.

⸻

🔧 Technologies Used
	•	Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
	•	Jupyter Notebook
	•	Logistic Regression (ML algorithm)

⸻

📊 Dataset Information

The dataset includes:
	•	Age, Gender, Income, Education
	•	Marital Status, Children
	•	Commute Distance
	•	Bike Purchase (Target: Yes/No)

⸻

🚀 How to Run
	1.	Clone the repository
  2.	Open bike_sales_project.ipynb in Jupyter Notebook.
	3.	Run all cells to see the complete analysis and model results.

⸻

✅ Results
	•	Model Accuracy: 65% on minmax scale, 64% on Standard Scaler
	•	Confusion Matrix, Precision, Recall, F1-score included in the notebook.
